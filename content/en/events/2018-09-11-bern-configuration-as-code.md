On Sep 11 we will meet at Digicomp Academy AG in Bern to talk about State of Jenkins and Configuration as Code.

Oleg Nenashev from CloudBees (Jenkins core maintainer and JCasC plugin contributor) will talk about recent changes and ongoing projects in the Jenkins community: Configuration-as-code plugin, Jenkins Evergreen, Jenkins X, and Cloud Native Jenkins. There will be also a hands-on demo of the Configuration as Code plugin and Docker packaging. We will also talk about the recent "Shifting Gears" blogpost by Kohsuke: [https://jenkins.io/blog/2018/08/31/shifting-gears/](https://jenkins.io/blog/2018/08/31/shifting-gears/) .

After the presentation, we will have an open discussion about Jenkins. If you are interested in particular topics, please propose them in RSVP.

Schedule:

- 18:00 - Intro and welcome
- 18:10 - Oleg Nenashev, Cloud Native Jenkins, Shifting Gears & Configuration as Code
- 19:20 - Open discussion: anything about Jenkins, or a second talk
- 20:00 - Networking and apéro
